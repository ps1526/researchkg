# researchkg
tool to build and visualize knowledge graphs of research papers from a single DOI/Paper Title/Concept + dumpable json representation and loading capabilities

next steps: semantic enrichment, Graph RAG, queries, talk to graph, programmatic access

Go to https://researchkg-frontend-zofbu2wefq-uc.a.run.app to interact with visualization and do things like filtering, view paper/abstract details, and paper/author selection and details.
Repo for visualization site can be found here: https://github.com/ps1526/researchkg_interactive/tree/main
